# 和弦組成音練習器

可直接開啟的繁體中文和弦組成音練習網頁。

## 使用

- 下載或直接開啟 repository 根目錄的 `index.html`，不需安裝套件、後端或外部資源。
- 在設定頁選擇題型、每題時間、答題數（5、10、15、20 或 30 題）與要練習的和弦類型，按「開始練習」。

## 功能

- 正向、反向與混合練習；涵蓋基本、延伸與變化和弦。
- 每題訂正時顯示和弦組成公式；結算頁顯示成績與錯題。
- PC 支援滑鼠、左右方向鍵與鍵盤輸入：C–B 不分大小寫，`+` 為升、`-` 為降。
- 手機可使用畫面上的音名與升降按鍵。
- 設定與訂正頁都可查看 TAB 譜方向、標準調弦的吉他指板音名圖。

此 repository 為可直接部署的單檔發布版本。

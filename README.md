# 和弦組成音練習器

可直接開啟的繁體中文和弦組成音練習網頁。

## 使用

- 本機可直接以瀏覽器開啟 `dist/index.html`；發布版本的單檔入口為 repository 根目錄的 `index.html`。
- 在設定頁選擇題型、每題時間、答題數（5、10、15、20 或 30 題）與要練習的和弦類型，按「開始練習」。
- 每個答案音使用單一格位顯示完整音名；格位上方的 `♯` 與下方的 `♭` 按鈕可切換升降記號。每個音只使用單一升或降記號。
- PC：點選音名格，或以 `←`、`→` 移動；`C` 至 `B` 不分大小寫，`+` 為升、`-` 為降。輸入下一個音名字母時，會自動前進到下一格。
- 手機：使用畫面上的 C–B、`♭`、`♯` 按鍵輸入；這組按鍵同時也可在 PC 點選。
- 和弦類型依「和弦組成公式」表分為基本和弦、延伸和弦與變化和弦；預設勾選全部基本和弦。可依小類逐一挑選或全選，並可按「查看吉他指板音名」開啟標準調弦、第 1 至 12 格的對照圖。指板只標示自然音 C、D、E、F、G、A、B，並採 TAB 譜方向：最上方為高音 E。
- 送出或時間到後，可按「顯示吉他指板」查看本題組成音位置；組成音以圓點標記，避免升降音名造成畫面混亂。
- 每題訂正時會顯示該和弦的組成公式。最後一題訂正後可查看結算：正確率、答對／答錯題數，以及錯題的和弦、公式與組成音。

## 維護

在本資料夾執行：

```powershell
npm test
npm run build
npm run test:dist
```

不需安裝套件；使用 Node.js 內建測試工具。
